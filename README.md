## Make it yours

| Feature | What you can do |
| --- | --- |
| **Preview and apply** | Try Vulphexis HQ or another theme. Choose which categories to apply, from wallpaper and Windows colors to desktop icons, mouse pointers, and sounds. |
| **Create and share** | Build a theme from your own assets, export it as a ZIP, or import one someone shared with you. |
| **Restore your desktop** | The app captures the settings it will change. **Release the Human** restores the saved settings. |

## Get started

1. Run the installer and open **Vulphexis Theme Manager** from Start. For the portable edition, extract the entire ZIP and open `FoxWorksThemeManager.exe` with the `_internal` folder beside it.
2. Select **Vulphexis HQ**, choose the categories you want, and click **Unleash the Fox**. Use **Validate Selected Assets** first if you want to check the files without changing Windows.
3. When you’re ready to go back, click **Release the Human**.

Wallpaper apply requires an existing static picture background so the app can capture it for restoration. If Windows is using Spotlight or a slideshow, leave wallpaper unchecked to apply the other categories.

## Upgrading from FoxWorks

Run the Vulphexis installer over your existing installation. The upgrade from v1.0.1 to v1.0.2 was tested in a Windows VM, including preservation of an imported GooseCorp theme.
